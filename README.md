# The Girl of Nevaeh

Family-friendly narrative adventure and companion games, based on the novel by R A Simpson.

**Build 2026-09-04 — full arcade suite**

Play online: [girlofnevaeh.com](https://girlofnevaeh.com)

## Play

Open the link on a phone or computer. On iPhone: Safari, then Share, then Add to Home Screen.

This build includes all of these on the home screen:

- Role Play
- Characters
- Warrior Battle
- Tic Tac Toe
- Chess
- Draughts
- Blocks
- Armageddon
- Quiz Time
- Memorizer
- Flip It
- Civil War
- Devil Run
- Game of 4
- Paint
- Flick
